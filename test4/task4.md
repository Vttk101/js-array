Вес Хэмминга — это количество единиц в двоичном представлении числа. Например, число 101 в двоичной системе записывается как 1100101, и в этой записи четыре единицы.
Задание
Реализуйте в файле solution.js и экспортируйте по умолчанию функцию, которая считает вес Хэмминга.
Примеры
hammingWeight(0) // 0
hammingWeight(4) // 1
hammingWeight(101) // 4
Подсказки
Метод toString() может помочь перевести число в двоичную систему. Он возвращает строку, поэтому цифры двоичной записи сравниваются со строкой '1'
