Реализуйте в файле solution.js и экспортируйте по умолчанию функцию, которая находит в массиве непрерывные возрастающие на единицу последовательности чисел и возвращает массив с их перечислением.

Последовательность состоит хотя бы из двух чисел, в которых каждое следующее больше предыдущего на единицу. Одиночное число в результат не попадает. Повтор числа или убывание обрывают последовательность.

Примеры
summaryRanges([]) // []
summaryRanges([1]) // []
summaryRanges([1, 2, 3]) // ['1->3']
summaryRanges([0, 1, 2, 4, 5, 7]) // ['0->2', '4->5']
summaryRanges([110, 111, 112, 111, -5, -4, -2, -3, -4, -5]) // ['110->112', '-5->-4']

Алгоритм учителя:
Учитель создал 2-е функции:
1-я функция составляет строку в виде диапазона из 1-го и последнего элемента массива

2-я функция summaryRanges([numbers])

    объявляет 2-а пустых массива:
    const ranges = []   // диапазоны
    let sequence = []   // последовательность

    Запускает обход numbers циклом for
        объявляет 2-е константы:
        const current = numbers[index]      //текущий индекс
        const next = numbers[index + 1]     //следующий индекс

        sequence.push(current) // текущий элемент - current сразу помещает в [последовательность]

        Если (текущий элемент + 1) !== последующему 
            Если длина [последовательности] > 1
                объвл-ся const range = 1-я функция(sequence) // появляется диапазон
                Этот диапазон помещают в массив диапазоны -> ranges.push(range)
            А [последовательность] опять делают пустым -> sequence = []
    взвращаются [диапазоны]  -> return ranges


Алгоритм от GPT:
- start хранит индекс начала текущей последовательности.
- Если следующее число на единицу больше предыдущего, продолжаем последовательность.
- Если последовательность прерывается, проверяем её длину.
- Если в ней минимум два числа, добавляем диапазон в результат.
- Начинаем искать следующую последовательность.

Сложность:
- Время: O(n) — один проход по массиву.
- Дополнительная память: O(k) — для хранения результата, где k — количество найденных последовательностей.
Решение также корректно обрабатывает пустой массив, одиночные числа, повторы и убывания.
